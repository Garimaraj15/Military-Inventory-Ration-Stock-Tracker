# Military Inventory & Ration Stock Tracker

## Overview

Military Inventory & Ration Stock Tracker is an Excel VBA-based inventory management system designed to manage military logistics efficiently. The project provides an interactive dashboard, automated reporting, inventory tracking, conditional alerts, and PDF report generation.

---

## Features

- Interactive Dashboard
- Dynamic KPI Cards
- Inventory Management
- Category-wise Analysis
- Low Stock Alerts
- Expiry Monitoring
- Conditional Formatting
- Automated Report Generation
- PDF Export
- Excel VBA Automation
- Data Validation
- Charts and Visualizations

---

## Dashboard

The dashboard provides live statistics including:

- Total Items
- Total Quantity
- Low Stock Items
- Expiring Soon
- Expired Items
- Ration Count
- Ammunition Count
- Equipment Count
